# Compiler Project

## Overview
This project is a simple compiler simulation that performs lexical analysis, syntax analysis, and basic error detection.

## Files Description

- lexer.java  
  Handles lexical analysis by breaking input into tokens such as keywords, identifiers, and operators.

- parser.java  
  Performs syntax analysis and checks whether the token sequence follows grammar rules.

- main.java  
  Acts as the driver program that connects lexer and parser and runs the overall process.

## Features

This project can detect:

- Syntax errors (missing operators, incorrect structure)
- Semantic errors (invalid or undefined elements)
- Extra or mismatched brackets
- Invalid tokens in expressions

## Purpose

The purpose of this project is to demonstrate basic compiler design concepts including tokenization, parsing, and error handling.
