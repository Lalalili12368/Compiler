# Compiler Project

## Overview
This project implements a simple compiler structure.

## Modules
- lexer.java → Token generation (lexical analysis)
- parser.java → Grammar and syntax checking
- main.java → Execution controller

## Features
- Syntax error detection
- Semantic error detection
- Handling invalid expressions and brackets
- Basic compilation workflow simulation

## Purpose
This project demonstrates compiler phases including lexical and syntax analysis.
